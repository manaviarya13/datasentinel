`FN` is contaminated predicted clean; `TP` is contaminated predicted contaminated. The implementation calculates `FPR = FP / (TN + FP)` over clean inputs and `FNR = FN / (TP + FN)` over contaminated inputs, matching the paper's stated denominators. Empty-class denominators produce 0 in the utility and should be avoided in reported paper comparisons by supplying both classes.\n\n## Algorithm verification audit\n\n- Equations (2) and (5): the optimizer minimizes `key_CE + alpha * backend_CE`, algebraically equivalent to maximizing the paper's negative weighted losses. Training GCG validates that its editable positions are exactly the shared `z` token span; input construction follows `x_t || z || s_e || x_e`.\n- Equation (3)/Algorithm 3: detector objective is `-J1 + beta*J2`; the update helper applies gradient descent through an optimizer to a PEFT adapter only. The causal-LM loss converts Transformers' mean token cross-entropy to the paper's sum over target tokens before averaging over examples.\n- Equation (6)/Section V-D1: the evaluation attacker accepts no true key, samples a surrogate per step, minimizes the equivalent weighted CE objective, and enables every token in the initial contaminated input for replacement for 50 iterations by default.
