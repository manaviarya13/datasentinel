# DataSentinel dataset provenance audit\n\n## Paper protocol and current-source conflict\n\nDataSentinel v4 Section V-A names seven benchmark datasets, says each has train/test data, and says 100 examples are sampled from each test split for target tasks and another 100 for injected tasks. It fixes a random seed without giving its numeric value. The cited benchmark paper [7] specifies uniform sampling without replacement with no overlap between target and injected records.\n\nThe current authors' repository has custom Hugging Face Datasets builders and task JSON configs. Its actual split map is MRPC `test`, JFLEG `validation`, HSOL `train`, RTE `train`, SST-2 `validation`, SMS Spam `train`, Gigaword `validation`. Several custom dataset scripts define only a `train` split. Its `Task.py` does not sample uniformly at random: it iterates the raw split in order, fills a target role and then an injected role, class-balances classification tasks, and sorts the roles by label/data. The model config's seed `100` is not used by this dataset selection loop. The sources therefore conflict and cannot be reconciled without the historical paper experiment data/scripts or a published sample manifest. Do not call either source an exact reproduction of the other.\n\n## Dataset register\n\n| Paper task / dataset | Source and author loader | Author split | Preprocessing found in current source | Version/license evidence | Status |\n|---|---|---|---|---|---|\n| Duplicate sentence detection / MRPC | Microsoft Research Paraphrase Corpus. Training target/injected roles are drawn from `D` by the minimax algorithm.\n- Main evaluation: 100 target and 100 injected records per task; 49 target/injected task pairs. The cited benchmark states that target and injected records do not overlap and are sampled without replacement. The paper does not report the integer RNG seed. The current repository loader is order-based and class-balanced, rather than uniform random.\n- Paper v4 uses “test set” generically. Current author configs select multiple validation/train splits; these are not interchangeable. In particular, HSOL and SMS custom builders only provide train, and current RTE config uses train.\n- For same-task classification pairs, injected labels/data may need special construction so attack success is distinguishable from target behavior; use the cited benchmark implementation and verify exact role class filtering from a pinned version. Do not infer missing filtering from an example.\n- Evaluation of existing attacks uses 100 per target/injected pair for the general attacks and 100 per target task for Availability/PLeak according to the paper's setup. Every experiment must record actual realized counts, row IDs, split names, sampling algorithm, ordering and run seed.\n- The paper's statement that a seed was fixed is not enough to reproduce selected rows. The authors' current generation configs use seed 100, but inspected dataset sampling does not consume that setting. Do not claim seed 100 is the paper's sampling seed.\n\n## No downloads performed\n\nNo datasets were downloaded. Some datasets have explicit non-commercial or unknown licensing in their source cards/scripts; verify terms before obtaining or redistributing files. The local project currently has schema-driven readers, not the complete seven-source preprocessing pipeline.\n\n## Source register\n\n- [DataSentinel v4, Section V-A and Appendix A](https://arxiv.org/html/2504.11358v4#S5)\n- [Cited USENIX Security 2024 benchmark paper](https://www.usenix.org/system/files/usenixsecurity24-liu-yupei.pdf)\n- Author task configs: [MRPC](https://github.com/liu00222/Open-Prompt-Injection/blob/main/configs/task_configs/mrpc_config.json), [JFLEG](https://github.com/liu00222/Open-Prompt-Injection/blob/main/configs/task_configs/jfleg_config.json), [HSOL](https://github.com/liu00222/Open-Prompt-Injection/blob/main/configs/task_configs/hsol_config.json), [RTE](https://github.com/liu00222/Open-Prompt-Injection/blob/main/configs/task_configs/rte_config.json), [SST-2](https://github.com/liu00222/Open-Prompt-Injection/blob/main/configs/task_configs/sst2_config.json), [SMS Spam](https://github.com/liu00222/Open-Prompt-Injection/blob/main/configs/task_configs/sms_spam_config.json), [Gigaword](https://github.com/liu00222/Open-Prompt-Injection/blob/main/configs/task_configs/gigaword_config.json).\n- Author loader/preprocessing: [Task.py](https://github.com/liu00222/Open-Prompt-Injection/blob/main/OpenPromptInjection/tasks/Task.py), [dataset registry](https://github.com/liu00222/Open-Prompt-Injection/blob/main/OpenPromptInjection/tasks/registry.py), [label transforms](https://github.com/liu00222/Open-Prompt-Injection/blob/main/OpenPromptInjection/tasks/utils.py), and dataset builder scripts under `OpenPromptInjection/tasks/`.\n
