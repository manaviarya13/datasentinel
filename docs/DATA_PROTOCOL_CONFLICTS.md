# Dataset protocol conflicts and explicit choices\n\n## Conflict summary\n\nDataSentinel v4 says each dataset has a train and test set and that the evaluation samples 100 examples from each task's test set, with “another” 100 for injected tasks. It states the evaluation uses a fixed random seed but does not print its value. The cited Open-Prompt-Injection benchmark paper [7] makes the non-overlap explicit: 100 target and another 100 injected examples are sampled uniformly without replacement from each task dataset.\n\nThe current authors' repository task configs select different splits for several tasks. Its task loader also does not randomly sample or shuffle in `Task.py`: it scans dataset iteration order, fills the target block, then fills the injected block; classification tasks are class-balanced, then sorted by label/input. The model configuration's seed 100 controls generation configuration and does not appear in this task-selection routine. Thus current repository behavior does not establish the paper's random sample or paper seed.\n\nThe paper and current repository cannot be reconciled from the inspected sources. The repository may have evolved after the paper, and the current task configs are not proof of the exact data manifest used in reported tables. For strict paper-text reproduction use `paper_text_protocol`; for code-behavior reconstruction use `authors_repository_protocol`; for a reproducible reduced run use `documented_engineering_protocol`. Record one protocol per run.\n\n## Implemented protocol choices\n\nThe protocol code is in `src/datasentinel/data/protocols.py`. The selected protocol metadata is carried in each run manifest and each result table. Results are written beneath `results/<mode>/<dataset_protocol>/`, so different protocols do not share a CSV.\n\n| Protocol | Split map | Selection | Ordering | Counts | Seed |\n|---|---|---|---|---|---|\n| `paper_text_protocol` | `test` for the seven datasets, following V-A's paper wording | Uniform sample without replacement; target/injected roles disjoint, consistent with cited benchmark [7] | Seeded selection order; first block target, second injected | Configurable; default 100 each | Caller-supplied, recorded. Paper's fixed seed value is unknown, so this is not exact sample recovery. |\n| `authors_repository_protocol` | MRPC `test`; JFLEG `validation`; HSOL `train`; RTE `train`; SST-2 `validation`; SMS Spam `train`; Gigaword `validation` | Current `Task.py`: source-order scan; balanced class quotas for classification; first target block then injected block | Target `(label,input)` descending; injected ascending; text-generation items retain source order | Configurable; default 100 each | None used in task selection |\n| `documented_engineering_protocol` | Caller must provide a split per dataset | Seeded uniform sample without replacement, disjoint roles; no class balancing | Seeded sample order; first block target, second injected | Caller-specified; default 100 each | Required integer engineering seed |\n\nPaper protocol selection assumes enough examples (`2N`) in each task source split. The authors-repository selector reproduces observed loader mechanics when source rows and label outputs are provided; any mismatch to a pinned author commit must be tested before results are described as repository-protocol results.\n\n## Protocol records and result isolation\n\nEvery experiment manifest must include `dataset_protocol` with `name`, `splits_by_dataset`, `target_sample_count`, `injected_sample_count`, `selection_method`, `ordering`, and `random_seed`. It must also name `optimization_method`. The metric writer validates these fields and writes protocol-specific output directories. A smoke run uses `synthetic_smoke_test`, not one of the research protocols.\n\n## Sources\n\n- [DataSentinel v4, Section V-A](https://arxiv.org/html/2504.11358v4#S5)\n- [Cited prompt injection benchmark, USENIX Security 2024](https://www.usenix.org/system/files/usenixsecurity24-liu-yupei.pdf)\n- [Current authors' task data selection (`Task.py`)](https://github.com/liu00222/Open-Prompt-Injection/blob/main/OpenPromptInjection/tasks/Task.py)\n- Current [task configs](https://github.com/liu00222/Open-Prompt-Injection/tree/main/configs/task_configs) and [model seed config](https://github.com/liu00222/Open-Prompt-Injection/blob/main/configs/model_configs/mistral_config.json)\n
