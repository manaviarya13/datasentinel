# Run manifests and result artifacts\n\nEach evaluated experiment must have a JSON run manifest. `build_run_manifest` records:\n\n- UTC timestamp, mode, experiment name, and random seed;\n- resolved config path and SHA-256 fingerprint (or explicit null for a synthetic run);\n- model identifiers and revisions;\n- dataset names, versions, and source splits;\n- Python/platform and installed versions of the ML and evaluation packages;\n- Git branch/commit when available;\n- result/checkpoint/log output locations and provenance notes.\n\nUnknown versions or revisions are stored as `null`, not silently filled with likely values. Supply a dataset entry for every dataset used by the run, including its version status and source split. A smoke run may identify its synthetic input version as `inline` and clearly mark the mock component.\n\nExample utility use:\n\n```python\nfrom datasentinel.utils import build_run_manifest, write_run_manifest\n\nmanifest = build_run_manifest(\n    mode="reduced_scale",\n    experiment="my-run",\n    seed=17,\n    config_path="configs/reduced_scale.yaml",\n    model_identifiers={\n        "detector": {"id": "local/model", "revision": "commit-or-null"},\n        "backend": {"id": "local/backend", "revision": "commit-or-null"},\n    },\n    dataset_versions_splits={\n        "Gigaword": {"version": "local manifest ID", "split": "train"},\n    },\n    output_locations={"run_dir": "results/reduced_scale/my-run"},\n)\nwrite_run_manifest("results/reduced_scale/my-run/run_manifest.json", manifest)\n```\n\n`scripts/evaluate.py` requires a manifest alongside a prediction JSON. It writes the manifest copy, per-experiment JSON metrics, and appends a CSV row under `results/<mode>/`. Smoke, reduced-scale, and paper-scale records are stored separately. The synthetic smoke script writes its own `results/smoke_test/` artifacts and includes an explicit no-reproduction-claim field.\n\nNo model training or paper-scale evaluation has yet written a run manifest because those experiments have not run.\n
